# MindHero 🧠⚡

משחק אימון יומי לקראת מבחן הקבלה לתכניות המחוננים בעל-יסודי (כיתות ו'–ט').

- ששת פרקי המבחן: הקשר מילולי, סדרות, אנלוגיות, היגיון, בעיות בחשבון, צורות
- גיבור שמשתדרג (3 סגנונות), כוחות תודעה עם השפעה אמיתית, רמות ודרגות
- תוכנית יומית מותאמת, משימת אבחון, קרב בוס מתוזמן, מעבדת טעויות, אקדמיית טקטיקות
- סימולציה בממשק שדומה למבחן הממוחשב, דו-קרבות, טבלת אלופים
- "קו פתוח" עם המנטורית נובה, ומסך הורה

אתר סטטי (HTML/JS) + Firebase Firestore לסנכרון.
